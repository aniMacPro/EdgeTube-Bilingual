# 映译 · YouTube 双语字幕

适用于 Microsoft Edge 的 Manifest V3 扩展，使用 DeepSeek 官方 API 翻译 YouTube 已有字幕，在播放器底部同步显示原文与译文。当前版本：**1.1.0**。

## 功能

- 原文在上、译文在下，白字搭配半透明黑底。
- 调节字号、原文和译文各自的字体粗细、字幕位置及背景深浅。
- API Key 可在设置中随时更换，保存在浏览器扩展本地存储。
- 能读取完整字幕时提前分批翻译；否则回退到读取当前 CC 字幕。
- 每条新字幕最多参考前 3 条原文及已有译文、后 2 条原文，帮助处理指代和术语衔接。
- 缓存区分视频、字幕位置、语言及邻近原文；支持暂停、跳转进度、倍速和播放器全屏。

## 安装

1. 下载本仓库 ZIP 并解压到固定文件夹，或克隆本仓库。
2. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本仓库根目录，即包含 `manifest.json` 的目录。
4. 打开扩展设置，填写自己的 DeepSeek API Key，保存并测试连接。
5. 打开或刷新 YouTube 视频，再开启“双语字幕”。

无需构建或安装 Node.js 即可使用扩展。更新文件后，重新加载扩展并刷新 YouTube 页面。请保留加载扩展时选择的文件夹。

## DeepSeek 配置与费用

默认模型为 `deepseek-flash`，接口为 `https://api.deepseek.com/chat/completions`。模型名可在“更多设置”中修改，以账户当前支持情况为准。

调用费用由使用者的 DeepSeek API 账户承担。“测试连接”也会产生少量用量。上下文参考和提前翻译会增加输入用量，不能保证零延迟或整段视频翻译完全一致。

插件本地译文缓存与 DeepSeek 服务端输入前缀缓存是两个独立机制。本地命中时不调用 API，因此不会计入 DeepSeek 后台的缓存命中统计。

## 隐私与限制

- 仓库不含 API Key；请仅在扩展设置中填写，不要提交到 Git。
- 请求从扩展后台发送到 DeepSeek 官方 API，不经过第三方中转，不收集遥测。邻近字幕和已有参考译文也会作为上下文发送。
- 本地 Key 不进行云同步，但本地存储不是操作系统级加密保险库。
- 依赖视频已有的人工或自动字幕，不包含录音、语音识别或画面文字识别。
- 系统画中画无法保证携带网页字幕叠层；请使用播放器全屏或剧场模式。
- YouTube 页面结构和字幕访问限制会影响兼容性。
- 已通过本地逻辑与 Edge 模拟场景检查；真实 YouTube 字幕到 DeepSeek 翻译的完整链路仍需在可正常播放的已登录环境中验证。

## 开发与测试

扩展使用原生 JavaScript、HTML 和 CSS，无运行时第三方依赖。

安装 Node.js 20 或更新版本后，在仓库根目录运行：

```sh
npm test
```

测试使用模拟 API，不需要 Key，也不会产生 API 用量。

主要文件：`background.js` 负责 API 与缓存，`bridge.js` 读取播放器字幕，`content.js` 负责同步及字幕叠层，`popup.html` 和 `popup.js` 提供设置界面，`core.js` 包含共享逻辑。

更多说明见 [使用说明](使用说明.md) 和 [验证报告](验证报告.md)。报告中的历史 API、网络和浏览器结果均带有验证时间，不代表当前服务状态。
